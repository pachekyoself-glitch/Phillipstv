No educational content is approved for the TV. The repository previously contained a policy and source shortlist, not a lesson library or installed application. This sheet links to the actual publisher resources so the parent and an institutional reviewer can inspect them.

The owner confirmed on 2026-11-04 that **formal institutional approval must cover the exact lessons and TV presentation**. Publisher origin, university accreditation, and parent acceptance do not replace that approval. Nothing on this page represents an endorsement of this project.

## What to review before approving any pilot

For each final item: age mode, exact text and narration, images and labels, learning objective, child readiness, every answer/feedback path, and adult involvement. Review the actual TV screens and remote interactions, including font size, focus indicators, session behavior and exit routes. Approval must identify the final bytes/version; changing content or presentation requires a new review.

The developer will assemble those final artifacts before asking for a release decision. Parent selection of a reference in this table does not authorize its copying, adaptation, deployment, external contact, or unsupervised use.
